## Hypothesis
Median d_l grows super-linearly through l = 0..6 then saturates around l = 8–10 (residual stream norm is bounded), AND median per-token cos(d_l, d_{l+1}) ≥ 0.6 in ≥4 of the early layers — the cascade is directionally coherent at the token level, not just on average.

## Setup
Create `experiments/per_token_divergence_cycle259.py`. Reuse cycle 258's data loader (200 wikitext-2 val × 128 = 25,600 tokens, seed 42) and cycle 258's `ReluPlusBleak(b_leak_l)` recipe where `b_leak_l = E_x[gelu(z) − relu(z)]` per 3072-dim channel is precomputed on the calib slice via a `c_fc` forward hook (12 distinct module instances, cycle 228 discipline). For each variant {A=GELU baseline, B=ReLU+b_leak}, run `collect_residual_trajectory(model, ids)` per seq on the full 200-seq calib, concatenate per-layer states along batch → 13 tensors each [B=200, T=128, 768]. Compute `U = get_unembedding(model)` (d_vocab × 768). For each layer `l ∈ 0..12`, compute `d_l = x_G^l − x_R^l` shape [200, 128, 768] and `per_token_d_l = pullback_norm(d_l, U)` shape [200, 128]; flatten to [25600]. Aggregate median / p10 / p90 per layer → 3 × 13 arrays. Per-token cos between d_l and d_{l+1} under G for `l ∈ 0..11`: `cos_l = pullback_inner(d_l, d_{l+1}, U) / (pullback_norm(d_l, U) * pullback_norm(d_{l+1}, U))` shape [200, 128], flatten → median over [25600]. Fit three curves to per-layer median d_l over l ∈ 0..12 (13 points): (i) log-linear `log(median) = a + b·l`, (ii) linear `median = a + b·l`, (iii) saturating `median = c·(1 − exp(−b·l)) + a`. Use `torch.linalg.lstsq` for log-linear/linear; scipy-free saturating via closed-form on `L = c + a`, `m(0) = a` with a 1-D grid on `b ∈ {0.05, 0.1, ..., 1.0}` then pick min-SSR.

## Risks

Flatten must preserve (B, T) order across variants for valid per-token cos. Use `torch.median(...)` via sorted p50 (tensors). Use `.double()` for the regression to avoid f32 cancellation.
