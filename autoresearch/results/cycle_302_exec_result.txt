== Geometric object ==
For a transformer block l with MLP z = LN2(x) @ W_fc + b_fc in R^3072 and
y = sigma(z) @ W_proj in R^768, and an activation pair (sigma, sigma_lin),
the curvature residual is:
    delta(z) = sigma(z) - sigma_lin(z)   in R^3072
    Dy(x)    = delta(z(x)) @ W_proj      in R^768

The framework computes five panels of Dy(x) measurements, parameterised by
(model, sigma, sigma_lin, blocks, calib_ids):
  P1: SVD(Dy)            -> rank_95, top singular values     (cycle 217 family)
  P2: SVD(Dy_centred)    -> top-20 right SVs . top-20 left SVs of
                            W_fc_{l+1} / Q_{l+1} / K_{l+1} / V_{l+1};
                            top-5 cos sum per reader         (cycle 218 family)
  P3: top-5 right SVs of Dy_centred -> wte @ v -> top-20 boost /
                            suppress vocab tokens             (cycle 235 family)
  P4: SVD(W_proj) -> span(Vh[:2,:]); E_kept_top2 =
                     ||Dy @ Vh[:2,:]^T||^2 / ||Dy||^2    (cycle 301 family)
  P5: b_leak = E[sigma(z) - sigma_lin(z)] (3072 per block);
      patch mlp.act with LinearisedAct(sigma_lin, b_leak);
      collect_residual_trajectory + compute_curvature ->
      rel kappa shift per layer                       (cycle 258 family)

Trainable params: 0 (no .requires_grad_(True), no .backward()).
