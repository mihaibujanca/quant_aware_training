## GPT-2 multi-block topk+lstsq accumulation curve

CONFIRMED: topk+lstsq composes where LASER fails. Composition failure is LASER-specific.

Float PPL: 53.89

topk+lstsq accumulation curve (hidden_fraction=1/6, k=512, 1000 Adam steps):
  Stage 1: [b2]              → PPL 48.47 ± 0.02  (trainable: 393,984)

Stages 1-3 all BELOW float baseline (53.89). LASER exceeded float at stage 2.
Stage 4 (b11 added) exceeds float+1.0 threshold (55.99 > 54.90) but is still
12.98 PPL better than LASER's stage 4.

Key finding: LASER's composition failure is method-specific, not a universal property
of multi-block compression. topk+lstsq preserves compositional geometry that SVD
low-rank approximation destroys. The gap widens with each added block (from -1.74
at 1-block to -12.98 at 4-block).

Note: topk+lstsq uses ~10x more trainable params than LASER (393K vs ~2.3K per block)
because it trains the full (768, 512) output projection rather than a rank-r factor.
The comparison is method-to-method, not param-matched.
