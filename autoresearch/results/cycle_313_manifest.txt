== Geometric object ==
For each block l in {0..11} and each rank r in {1, 2, 4, 8, 16, 32, 64}:

  Uncentered SVD truncation:
    W ∈ R^{3072 × 768}  (HF Conv1D layout: applied as x @ W)
    SVD(W) on CPU float32 -> U (3072, 768), S (768,), Vh (768, 768)
    W_r = U[:, :r] @ diag(S[:r]) @ Vh[:r, :]    -- standard rank-r truncation
    Replace c_proj_l.weight <- W_r in place; eval PPL; restore.

  Calibrated SVD-LLM weighted SVD truncation:
    Capture X ∈ R^{N_tokens × 3072} = inputs to c_proj_l across 200 calib
      seqs × 128 tok = 25,600 rows (forward pre-hook on the c_proj_l module).
    Sigma_l = X^T X / N ∈ R^{3072 × 3072}, symmetric PSD covariance estimate.
    A_l = Sigma_l^{1/2} via symmetric eigendecomposition (eigh):
      Sigma_l = V D V^T -> A_l = V diag(sqrt(max(D, 0))) V^T
    A_l_pinv = V diag(1 / sqrt(D))_+ V^T  (eigenvalues clipped at
      1e-6 * max(D))
    SVD(A_l @ W) = U_w S_w Vh_w
    Truncated:  AW_r = U_w[:, :r] @ diag(S_w[:r]) @ Vh_w[:r, :]
    W_r = A_l_pinv @ AW_r
    Replace c_proj_l.weight <- W_r in place; eval PPL; restore.

  This matches the SVD-LLM (Yuan et al., 2024) weighted SVD formulation:
  the optimal rank-r approximation of W under the input-weighted Frobenius
  loss ||x W - x W_r||^2 = ||(W - W_r)^T x||^2 averaged over x is found by
  minimizing ||A_l (W - W_r)||_F^2, which is a standard SVD truncation
  problem in A_l-space.

== Constructive follow-ups ==

1. **Activation-rank LASER vs weight-rank LASER**: cycle 313 truncates W
   in the input-whitened space, but the cycle 309 result (block 8 dy-aligned
   LASER REFUTED comparative claim) suggests the input-side spectrum is
   the binding constraint, not the output-side direction. A direct test:
   project W onto the top-k right singular vectors of the WHITENED INPUT
   X A^{-1}, not on the top-k singular vectors of A W. Closely related
   to ASVD (Yuan et al., 2024).

2. **r=2 retrain on b3, b8, b9 as missing anchors**: cycle 313 uses
   float as the soft anchor for blocks where no published r=2 retrain
   exists. A 3-block 4000-step Adam r=2 retrain at b3, b8, b9 would
   give the true CONFIRMED bar for these blocks. Expected wall: 9 fits
   * 2 min/fit = 18 min on mps.

3. **b0 catastrophic outlier audit**: c_proj_0 SVD truncation gives
   PPL >89 even at r=64 (calibrated). Investigate why; cycle 278 reports
   b0 c_proj output eff_rank = 71.93 (HIGHEST of all 12 blocks). The
   no-train SVD truncation at any rank below the eff_rank floor breaks
   the model. Calibration helps by 4.9x at r=64 but is still unusable.
   c_proj_0 is the post-LayerNorm-on-embeddings layer; its operator
   structure may be qualitatively different.

4. **Cycle 304 k_95 prediction vs cycle 313 calibrated PPL**: cross-check
   whether the k_95 census (predicted compression rank from curvature)
   correlates with the cycle 313 calibrated rank where PPL flattens to
   <60. If yes, k_95 is a useful proxy for the no-retrain LASER capacity.

5. **Cycle 280 + cycle 313**: combine calibrated SVD init with cycle 280
   Adam retrain at b1 r=2. Predict: starting from calibrated init 56.70
   instead of uncentered init 57.66, Adam should still converge to ~49.03
   (~7.67 PPL recovery in 4000 steps). If the FINAL converged PPL is the
   same (~49.03) regardless of init, this confirms the retrain gap is a
   non-SVD optimum (Adam goes off the SVD basis). If the calibrated init
   converges to ~46-47, the basis choice helps Adam too.
