== Geometric reading (the substantive answer) ==
1. Item 311 verbatim REFUTED at all four blocks tested. Block 1 = 74.63 pct
   of curvature in the kept 2D, block 2 = 91.90 pct, block 11 = 98.03 pct,
   block 0 = 59.02 pct. The "LASER denoises curvature for free" reading
   does NOT survive: cycle 280's rank-2 kept subspace IS the curvature
   residual subspace.

2. The (GELU, ReLU) curvature residual delta(z) lives in the same 2D-ish
   block-1 right-singular structure that LASER keeps. This is the
   geometrically clean explanation for cycle 258's kappa kink (+47.7 pct
   at layer 4 under ReLU swap): swapping GELU for ReLU at layer 4 ablates
   the dominant component of delta(z), which is exactly the component that
   c_proj's top SV reads -- so the pullback geometry visibly shifts.

3. The connection cycle 217 ('Delta_centered rank_95 <= 64 in 9/12 blocks')
   + cycle 258 (kappa kink) + cycle 280 (rank-2 LASER) + cycle 300 (both
   directions of A are unigram axes) collapses into a single statement at
   block 1: the curvature residual, the rank-2 LASER kept subspace, and
   the unigram-frequency axis read by block-2 K all live in the SAME 2D
   plane in R^768. The compressible signal at block 1 is not 'unigram'
   alone, it is 'unigram-modulated GELU curvature'. This is a much
   stronger interpretive claim than item 311's CONFIRMED branch would
   have allowed.

4. Block 11 has E_top2 = 0.980 -- 98 pct of the curvature lives in 2 of
   768 directions of W_proj. Cycle 278 reported eff_rank(c_proj_11 OUTPUT)
   = 22.49, NOT ~2. This is not a contradiction: eff_rank measures the
   energy distribution across all output singular values; the curvature
   residual specifically is far more rank-1/2 concentrated than the
   block's overall output. The curvature is structurally low-rank even in
   blocks where the block as a whole is not.

5. Block 0 has E_top2 = 0.590, the lowest of the four blocks. The
   curvature residual at block 0 still concentrates 60 pct in the top 2 SV
   directions (vs random null 0.003 -- 225x), but is the least anisotropic
   block. This is consistent with cycle 217's finding that block 0 had a
   ~1D unigram-frequency axis: the rank-1 piece dominates (E_top1 = 0.522)
   but the second SV adds less than the deeper blocks.
