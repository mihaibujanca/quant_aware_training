== Geometric object ==
For an activation pair (sigma, sigma_lin) and GPT-2 transformer block l:
  z(x)  = LN2(x) @ W_fc + b_fc           in R^3072  (per token)
  delta = sigma(z) - sigma_lin(z)        in R^3072  (curvature residual)
  Dy    = delta @ W_proj                 in R^768   (residual stream impact)
W_fc shape (768, 3072), W_proj shape (3072, 768) -- HF Conv1D convention.
The unified framework computes five panels of measurements on Dy(x):
  P1: SVD(Dy)        -> rank_95, rank_99, top singular values  (cycle 217 family)
  P2: SVD(Dy_centred) -> top-20 right SVs vs block l+1 c_fc/Q/K/V reading
                         left-singular subspaces; top-5 cos sum  (cycle 218 family)
  P3: top-5 right SVs of Dy_centred -> top-20 boost/suppress vocab tokens
                          via wte @ v  (cycle 235 family)
  P4: SVD(W_proj) -> kept 2D output subspace span(Vh[:2,:]); E_kept_top2 =
                     ||Dy @ Vh[:2,:]^T||^2 / ||Dy||^2  (cycle 301 family)
  P5: per-block b_leak = E[delta] (3072-dim first-moment correction);
      patch all 12 mlp.act with LinearisedAct(sigma_lin, b_leak); collect
      pullback kappa via aleph.pullback_geometry.collect_residual_trajectory +
      compute_curvature; report rel kappa shift per layer  (cycle 258 family)

   are now one parameterised module with one driver. This eliminates the
   GELU-specific framing of "the bump" -- the framework treats curvature as
