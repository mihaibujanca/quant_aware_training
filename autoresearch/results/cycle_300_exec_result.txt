== Substantive findings ==
1. Item 310's hypothesis is PARTIALLY RIGHT, PARTIALLY WRONG.
   RIGHT: direction 0 IS the unigram/stopword axis (17/20 boost tokens are
   stopwords, matching cycle 217/235's unigram findings).
   RIGHT: both directions read from mostly-negative / bump channels, not
   from mostly-positive channels (0 mostly_pos in either top-20).
   WRONG: direction 1 is NOT "more semantically structured". It is ANOTHER
   unigram/stopword axis (19/20 boost tokens are stopwords) -- even more
   extreme than dir 0.

2. Both rank-2 directions encode variants of unigram frequency, and together
   they span the "block-1 c_proj writes the unigram axis" operator. The
   reason block 1 eff_rank is 2 (not 1) is that there are TWO different
   projections of the unigram cluster, not one unigram + one semantic.

3. The SVD init is already structurally final. trained INT init = 17/20 and
   19/20 -- Adam's 4000 steps change at most 3 tokens in each top-20 boost
   list. The ~8.6 PPL recovery from Adam is NOT moving the token-level
   semantics; it is a small basin-refinement within the unigram plane plus
   bias fine-tune. This is consistent with cycle 299's "83 pct of optimal
   basin from SVD init" finding.

4. Block-2 K-reader alignment is STRONG for both directions (~12 sigma
   above null for dir 0, ~14 sigma for dir 1). Block-2 attention keys read
   the unigram axis heavily -- consistent with attention learning to
   attend-to-frequent-tokens (cycles 217/218 patterns). Block-2 V alignment
   is weaker (dir 0 ~3 sigma, dir 1 below null). Q alignment ~2.7-4.5
   sigma. The geometry is: block 1's 2D c_proj writes a unigram/stopword
   axis into the residual stream; block 2's K-reader reads that axis back.

5. "Zero mostly-pos channels" is the strongest single observation: in R^768
   the top-20 |A[c, i]| channels for i=0, 1 contain NO channel with sigma
   >= 0.9. The rank-2 bottleneck is entirely powered by GELU bump / dead-
   side channels, not by the "always-on" channels. This is the exact
   opposite of a "always-on linear subspace" story, and it supports the
   cycles 258/280/311 theme that GELU curvature is where the compressible
   signal lives.

6. The "direction 1 unigram too" finding makes item 311 / cycle 311 more
   interesting: if BOTH rank-2 directions are unigram, then the cycle 280
   frozen A factor is essentially a 2D basis for the unigram axis, and the
   question "does the (GELU, ReLU) curvature residual live in col(A) or
   col(A)^perp" becomes "does the curvature contribute to unigram or
   semantic reading".
