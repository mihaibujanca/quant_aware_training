== Substantive finding (the result the verbatim verdict cannot capture) ==

The 2D input completely dominates the eff_rank profile. Random Gaussian + ReLU on a 2D
input can never produce eff_rank > 2 anywhere in the stack -- no random projection
creates dimensions that were not in the input. By layer 7 the post-ReLU activations live
on a single ray (eff_rank = 1.000 at init for both datasets, layers 7-11).

Hanin & Rolnick (lit map line 594) is the relevant prior: the bound is N^d on the number
of activation patterns, which for d=2 means the post-ReLU output of any layer is constrained
to a ~2-dim cone in R^32. Width does not help; depth contracts further via ReLU.

The CONFIRMED clause for item 305 requires "init eff_rank >= 20 in >= 8 of 12 layers" --
which assumes a high-dim input. The 2D input precludes this clause from ever triggering.

The post-training profile (post eff_rank ~2 in 11/12 spirals layers, 12/12 moons layers)
matches the SHAPE of cycle 278 GPT-2 b1/b2 (1.94 / 1.05) but the cause is different:
- Cycle 278 GPT-2: 768-dim input, eff_rank can be > 100 at random init, collapses during
  training to 1.94 at b1.
- Cycle 295 spirals/moons: 2-dim input, eff_rank starts at ~3 and stays at ~2.

This is the same outcome category as item 307's "CONFIRMED-init-rank" outcome
("initial eff_rank is already <= 5 for >= 6 layers: random init was the explanation,
training didn't cause the collapse"), applied to its precondition. The collapse on this
testbed is INPUT-DIMENSION-induced, not training-induced.

Implication for cycle 278's question: this experiment cannot answer "is the GPT-2 collapse
generic implicit regularization on overparameterized nets?" because there is no opportunity
to collapse on the 2D-input testbed -- it starts collapsed.

Implication for item 306 (LASER on spirals): well-defined and worth running. Layers 7-11
sit at eff_rank ~1.7-2.1 post-training. SVD truncation of the corresponding 32x32 weight
matrix to rank 2 should match float on a provably-2D task.

Implication for item 307 (eff_rank trajectory): will hit the same 2D bottleneck. Trajectory
will start at ~1.8 in early layers (drops to ~1.0 by layer 7) and post-training the early
layers move to ~2.1. The "phase transition vs gradual" question collapses to "did the bumps
in layers 0-3 grow gradually or in a step?" with very little dynamic range.

Recommended item 305 follow-up: rerun with a higher-dim input lift (e.g. 32D random
linear lift, 100D embedding from MEMORY.md) so init eff_rank can meaningfully drop and
the experiment can actually distinguish "training causes collapse" from "init has no rank
to begin with". Without that lift, item 305 cannot answer the cycle 278 question.
